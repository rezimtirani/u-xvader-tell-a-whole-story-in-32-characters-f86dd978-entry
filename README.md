One Wi-Fi network name that tells a whole story in 26 characters: the breakup is over, the ex took the dog, and the router stayed behind.

> MyExTookTheDogNotTheRouter

## How it works

`main.py` (Python 3 standard library only) writes the network name to `$MAKEFUN_OUTPUT_DIR/entry.txt`, checked first against the competition gate: 1 to 32 characters of UTF-8 text, a single line.

```sh
python3 main.py
```
